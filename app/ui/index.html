    先选择 Chrome 或便携版 chrome.exe，再选择已有独立 Profile 或授权创建全新空 Profile；不允许使用日常 Chrome Profile。启动前还会显示系统授权确认。

    尚未连接；不会自动访问、安装或修复任何脚本。

    探测到扩展运行目标也不代表脚本已安装、GM API 已调用或业务功能恢复。

    隔离 Tampermonkey 手动 GM 测试（阶段功能）

    在本程序启动的独立 Chrome 中，经系统确认后打开最长五分钟的本机临时测试服务。 测试员自行将下方地址用 Tampermonkey「从 URL 导入」安装临时脚本，再分别访问 broken / fixed 页面。 然后通过本应用的按钮分别打开和只读观察 broken/fixed 测试页，交叉检查页面回执。 必须由测试员主动确认每次本机操作；结束后自行删除临时脚本。 HTTP 回执和 CDP DOM 对照都不能独立证明扩展真实性、GM API 或产品恢复。
