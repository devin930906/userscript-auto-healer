Userscript Auto Healer

当前支持只读导入、静态选择器分析与获授权的独立 Chrome/CDP 连接；默认不修改原始脚本或自动安装脚本。只有在单独的原生手动恢复流程中，经过两次系统确认才会尝试替换用户选定的本地脚本。只有经过独立原生授权的双选择器场景才可生成新的人工审核候选文件。静态结果或管理器运行目标提示不代表 Tampermonkey、GM API 或真实业务恢复验证，自动修复尚未开放。

    导入脚本的测试场景登记（当前会话）

    仅为已导入且校验过字节的脚本建立本机会话场景。不会访问目标网站、执行脚本、保存凭据或验证 Tampermonkey。登记准备就绪并不等于实际测试通过。

    提供替代选择器时，将在同一已授权页面检查两个选择器。只有旧选择器持续缺失且替代选择器持续存在，才展示“人工审核线索”；不自动修改或安装脚本；需要独立原生授权及真实只读 DOM 取证才能手动导出候选文件，这不视为已验证的补丁。

    尚未查询观察历史；此功能不需要启动 Chrome。

      人工候选导出仅支持通过系统选择器导入的本地 .user.js 文件及两项已登记选择器。每次操作将重新授权在本应用归属 Chrome 中读取 DOM、通过原生选择器分别选取备份目录和候选目录，并在真正写入前再次请求系统确认。脚本 SHA 不匹配、DOM 不稳定、旧元素仍存在或新元素缺失时拒绝。导出前会在独立备份目录持久保存恢复检查点；若检查点不能核验则不会继续导出。恢复检查点不提供自动应用或回滚权限。候选不等于 Tampermonkey、GM 或业务验证，不提供自动安装和回滚。

      人工导出在最终系统写入确认之前可以取消；开始创建独立备份／候选之后不能撤销既有文件，原始脚本仍不被覆盖。若中断请检查所选输出目录。

      检查只限独立 Chrome、无需登录且仅包含一或两项 CSS 存在性断言的场景。每次访问需要系统确认，最多三次 DOM 计数，并在同一受控标签页观察 1.2 秒页面 JavaScript 异常次数；只返回计数，不收集异常消息、堆栈或脚本源码。即使出现页面异常也无法归因 Tampermonkey；窗口没有异常不代表业务正常。

      每次通过授权的完整只读 DOM 与短时异常检查后，仅在内存中登记该脚本的有限观察历史（最多 32 条，关闭窗口即清除）。可随时查看逐次观察时间与保守结果；此界面不显示脚本路径、源码或证据哈希。元素存在不代表油猴脚本运行正常；异常或选择器缺失只记为证据不足，不表示自动修复或恢复。未授权、取消或失败的检查不写入历史。

        此功能仅供已拥有本工具生成的、与当前脚本完整路径绑定的独立 .backup.user.js 备份时使用。先选择需要恢复的本地 .user.js，再选择原始备份；将严格比对两者身份与字节。最终确认后，程序先独立备份当前被替换版本，再写恢复意图并尝试原子替换。操作不能被视为脚本自动修复，也不更新 Tampermonkey 已安装版本。

        尚未请求恢复。若出现中断或错误，请检查所选备份目录和原始文件；不要盲目重复操作。
